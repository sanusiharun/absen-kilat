# Verification policy
Admin: npm ci, npm run lint, npx tsc --noEmit, npm run build; browser checks at 360/768/1024/1440 widths, light/dark, keyboard and role scenarios. Backend: go test ./... and go vet ./... from backend. Mobile: inspect package scripts, typecheck and applicable tests; device-only camera/GPS checks recorded separately. Use targeted checks during iteration and applicable full checks before delivery. Record command, revision, exit code, evidence and skipped checks. Never substitute static inspection for execution. Existing CI remains authoritative until reconciled. Validator checks document presence only; it does not prove approval or correctness.
