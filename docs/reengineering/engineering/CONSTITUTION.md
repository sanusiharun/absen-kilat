# Constitution
1. Preserve observed behavior until a change is approved.
2. Separate observed, inferred, desired and unknown requirements.
3. Backend enforces authorization; UI visibility is not security.
4. Protect PII, credentials, location and attendance photos; use synthetic test data.
5. Prefer existing stack and minimal changes.
6. Every nontrivial change has traceable requirements, acceptance scenarios and evidence.
7. Human owns scope, design and release approval.
8. No false PASS, silent scope expansion, destructive migrations or unapproved deployment.
