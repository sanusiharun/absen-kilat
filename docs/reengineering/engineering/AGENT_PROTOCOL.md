# Agent protocol
Logical roles: discoverer/planner, architect, implementer, reviewer. One agent may perform multiple roles but cannot grant human approvals. Reviewer independently checks spec compliance, authorization, regressions and evidence. Read index then scoped rules and relevant skill; avoid loading all docs. Claude and Codex use shared .agents/skills via explicit path fallback. Record change ID, revision, completed tasks, remaining work and blockers in change verification.md. No external orchestration or vector store required. Never expose secrets or production personal data.
