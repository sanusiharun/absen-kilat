# Approval protocol
G1/G2 approvals must be human-authored GitHub comments or equivalent verified owner records, referencing change ID, gate and SHA-256 digest of reviewed artifacts. G1 covers proposal; G2 covers proposal, design, tasks and all spec files. Recompute digest before dispatch; changed content invalidates affected gate. Verify author against explicitly configured owner allowlist and retrieve records directly from trusted API. Reject agent authors, ambiguous approvals, missing records, stale digests and revoked approvals. G3 requires actual test/review evidence; G4 human authorization. Structural validator and CI do not authenticate approval. Runtime enforcement is pending; autonomous dispatch remains disabled.
