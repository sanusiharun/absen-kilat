# DEFAULT workflow
Discover: inventory routes, handlers, services, persistence, tests and UI; cite paths and baseline SHA. Propose: goals, non-goals, risks, dependencies; G1 human approval. Specify/design: SHALL requirements, Given/When/Then scenarios, contracts, task IDs and verification plan; G2 human approval. Approvals must identify change ID and reviewed revision; material edits invalidate affected approvals. Implement only approved tasks on isolated branch. Verify G3: targeted tests, applicable CI checks, independent review for high-risk changes, evidence with commands and exit codes. G4 human merge/release approval. Archive only after delivery; reconcile canonical feature specs. Small docs/typo changes may use recorded fast path without behavior changes. Missing evidence or approval means BLOCKED. No repeated review loops without new findings.
