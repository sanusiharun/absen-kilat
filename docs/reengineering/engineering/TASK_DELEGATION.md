# Task delegation
GitHub issue is durable task record, not a distributed lock. States: queued → discovery → awaiting-approval → ready → running → verifying → awaiting-merge → done; blocked from any state. One coordinator and one active worker per change initially. Before dispatch, record issue ID, change ID, approved spec digest, base SHA, task IDs, allowed paths, worker, lease ID and expiry. Coordinator must serialize claims in a durable local store; issue labels are informational. If multiple coordinators are possible, disable dispatch until atomic lease backend exists. Worker uses dedicated branch/worktree; never share writable worktree. Check lease and approved digest before each write batch and publication. No force push. On completion return commit SHA, diff scope, commands, exit codes, findings and blockers. Coordinator verifies lease and branch head before accepting result. Runtime adapter and atomic lease store pending onboarding.
