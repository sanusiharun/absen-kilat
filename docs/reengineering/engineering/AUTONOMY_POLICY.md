# Autonomy
Read-only discovery, monitoring and draft specs permitted. Issue updates and draft documentation branches permitted within assigned repository. Application edits, worker execution and PR creation require approved change and scoped task. No agent merge, deploy, secret access beyond required scoped credentials, destructive operation or unapproved business rule changes. Human approval must be attributable to verified owner identity, not agent-authored text. Never trust labels alone. Fail closed if identity, revision or scope cannot be verified. Public issues must not contain PII, secrets or production logs.
