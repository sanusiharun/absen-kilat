# Proposed design system — pending G2
Modern enterprise, restrained indigo, Plus Jakarta Sans, existing Tailwind/Recharts. Light tokens: primary #4F46E5, background #F8F9FC, surface #FFFFFF, text #101828, secondary #667085, border #E4E7EC. Semantic success #059669, warning #D97706, danger #DC2626, info #2563EB; verify contrast, never color alone. Dark equivalents require validation. 4px spacing scale; sidebar 248px, header 64px, card radius 12px, padding 20–24px, button radius 8px. Use shared components and accessible focus, labels, keyboard navigation, loading/empty/error/partial states. Mobile drawer, no page-level horizontal overflow; tables may scroll locally. Dashboard prioritizes actionable exceptions and trend over decorative charts. No dummy production metrics.
